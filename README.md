# 🌸 Юки 3D — Мой карманный компаньон (Talking Tom Style 3D Game)

> **Жанр:** 3D Anime Virtual Companion / Tamagotchi / Talking Tom 2.0  
> **Стиль:** Кавайный 3D Chibi Toon-Shading (Genshin / Kyoto Animation aesthetic).  
> **Технологический стек:** Three.js WebGL 3D, WebAudio API DSP, MediaRecorder Voice Engine, Real-Time Lip-Sync.

---

## 🎮 Ключевые особенности и 3D-механики

1. **Честный объёмный 3D-персонаж (Yuki Chibi Rig):**
   * Объёмная голова с большими аниме-глазами, веками и слежением взгляда за пальцем/курсором.
   * Процедурная физика кошачьих ушек и хвостиков (Spring Physics sway).
   * 3D-рот с динамическим открыванием для еды, жевания и синхронизации речи.
   * Тактильные зоны касания (Raycasting): поглаживание по макушке вызывает мурчание, румянец и жмурки; щекотка животика — смех и увороты.

2. **Единый 3D-мир с кинематографичными свайпами (4 комнаты):**
   * **🛋️ Гостиная:** Уютный диван, коврик, столик с ретро-консолью и микрофон голосового повтора.
   * **🍱 Кухня:** Обеденный стол со скатертью, тарелка и Drag & Drop еда (онигири, яблоки, торт, бургеры). Юки открывает ротик при поднесении еды и аппетитно жует со звуком хруста.
   * **🛁 Ванная:** Полная 3D-ванна, мыльная губка (намыливание пузырями) и душ с эффектом всплеска теплой воды.
   * **🌙 Спальня:** Кровать с мягким пледом, винтажный ночник с тумблером (физическое гашение света, полумрак и сладкий сон «Zzz...»).

3. **Голосовой повторитель Talking Tom (Voice Engine + Lip-Sync):**
   * Запись звука через микрофон браузера (`MediaRecorder`).
   * Повышение частоты и ускорение речи (Pitch-Shift) для получения ультра-милого детского аниме-голоска.
   * Анализ частот в реальном времени (`AnalyserNode`) — 3D-рот Юки открывается строго в такт повторяемой фразе.

4. **Ретро-аркада «Сладкий Ловец» (60 FPS Canvas):**
   * Запуск с консоли в гостиной: ловля вкусняшек корзинкой на скорость и реакцию для заработка монет.

5. **3D Гардероб:**
   * Мгновенная примерка костюмов (Классический розовый, Сейлор-мун, Горничная, Пижамка).

---

## 🚀 Быстрый запуск

1. Откройте `index.html` в любом современном браузере (Chrome, Edge, Safari, Firefox).
2. Разрешите микрофон (при нажатии на кнопку «🎙️ Повтори голосок!»).
3. Для наилучшего погружения откройте режим мобильного устройства (`F12` $\rightarrow$ `Ctrl+Shift+M` в браузере).
